# API de Gestão de Tarefas (CRUD)

API RESTful para gerenciamento de tarefas desenvolvida com **FastAPI** e banco de dados **MySQL**.

## 🚀 Tecnologias Utilizadas
- **Python 3**
- **FastAPI** (Framework web)
- **Uvicorn** (Servidor ASGI)
- **Pydantic** (Validação de dados)
- **mysql-connector-python** (Conexão com banco MySQL)
- **MySQL Workbench**

## 📌 Funcionalidades
- `POST /tarefas` - Cadastra uma nova tarefa
- `GET /tarefas` - Lista todas as tarefas cadastradas
- `PUT /tarefas/{id}` - Atualiza uma tarefa existente pelo ID
- `DELETE /tarefas/{id}` - Remove uma tarefa pelo ID
